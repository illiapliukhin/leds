# ERC waivers (mono_electronics schematic)

Intentional or accepted ERC findings while the schematic remains a **PCB net mirror** (not a full design-rule-clean capture).

| ERC type | Scope | Waiver rationale |
|---|---|---|
| `single_global_label` | Per-sheet ERC | Hierarchical sheets use **local labels**; the same net name appears once per sheet by construction. Full-project connectivity is checked by `tools/compare_sch_pcb_nets.py` against the PCB. |
| `lib_symbol_issues` (`power` library) | All sheets | `power:GND` / `power:PWR_FLAG` are embedded in each `.kicad_sch` `lib_symbols` section; CLI ERC still warns that the global KiCad `power` library is not configured. |
| `footprint_link_issues` | Passives / symbols | Footprints live under `hardware/libraries/`; filters may not match autogenerated box symbols until symbols are replaced with vendor KiCad libs. |
| `power_pin_not_driven` | `#PWR01 GND` on isolated sheets | Each sheet carries its own GND power symbol + PWR_FLAG stub; hierarchical power distribution is not modeled—PCB has continuous `GND`. |
| `pin_not_connected` / `label_dangling` | Complex connectors (`J_USB`, `U_ESD`) | Autorouted pin order on box symbols may not match visual pin side; **net names and pad numbers still match the PCB manifest**. |
